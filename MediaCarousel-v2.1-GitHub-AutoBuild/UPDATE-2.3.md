# MediaCarousel 2.3

- 右側實際音訊電平表：L/R sample peak、RMS、dBFS、1.5 秒峰值保持與 CLIP 指示。反映選取來源與音量推桿的訊號電平；不是系統總混音或喇叭音壓。多畫面請先選取要監看的格子。
- 格子選檔及建立空格不再新增播放列表。格子來源保存在專案中，原列表不會被複製或修改。
- 移除右側「＋照片／影片」，保留從播放列表選檔與左側套用來源。
- CUE 保存正在播放的媒體、影片播放位置、剪輯起訖、音量、單畫面位移／縮放、多畫面幾何、畫布及播放模式。GO 召回並從記憶位置播放；「下一個 GO」進入下一段。
- CUE 使用獨立設定快照，修改原列表不會改動已記錄 CUE。來源檔案仍需存在；媒體遺失時不切換目前畫面。轉場中請等轉場完成再記錄。
- 左側「＋黑畫面」新增內建黑場素材，可調整秒數、排序、輪播、套用格子及記錄為 CUE，無需外部圖片。

舊版場景沒有保存單畫面媒體來源，需重新播放來源並按「記錄 CUE」。舊版已產生的重複列表保留，避免刪除使用者資料；新版不會繼續增加。

測試：已知 PCM 四種格式電平、實際 AAC 音訊監看與靜音衰減、單／多畫面影片 CUE 定位、來源列表變動後的獨立召回、專案保存還原、黑場、原畫布／縮放／播放測試。
