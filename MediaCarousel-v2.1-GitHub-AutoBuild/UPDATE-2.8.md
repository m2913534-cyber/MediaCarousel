# MediaCarousel 2.8 · 中央播放及輸出參數

中央預覽下方、主音量與音量百分比旁新增「播放及輸出 ▾」，點開即可調整：輪播模式、切換效果、轉場時間、PDF 自動輪播、結束停留最後一幀、單畫面填滿、投影比例、畫布像素／4K、輸出螢幕與預覽視窗。

原右側「播放／輸出」分頁移除；所有操作沿用原本的控制項、訊號及儲存設定。四種介面風格與四種配置都固定在主音量旁提供此入口。

參數使用可捲動的浮動面板，開關時不改變預覽畫面的大小。可按「收起」、Esc 或點外側關閉；輪播、音量及正在輸出的影像持續運作。開啟畫布設定、輸出螢幕或預覽視窗時先收起面板。

保留 2.7 的播放效率優化、直立 FADER、即時靜音、單畫面自由寬高、多畫面強制滿版、CUE、PDF 及簡報控制功能。不改變影片解碼、幀率與畫質設定。
