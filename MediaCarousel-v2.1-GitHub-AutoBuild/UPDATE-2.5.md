# MediaCarousel 2.5 · PDF 與 PowerPoint 簡報

## 播放方式

在左側素材列表加入 PDF、PPT、PPTX、PPS 或 PPSX，選取後按播放，或以右鍵選擇放映。上方「簡報」選單可偵測 PowerPoint 桌面版及開關簡報筆按鍵。

- **PDF**：程式內直接繪製頁面，可輸出至原有畫布、外接螢幕或多畫面格子；支援滿版、單畫面拖曳縮放、指定頁碼、上一頁／下一頁、黑畫面及 CUE 頁碼記憶。
- **PDF 自動輪播**：在「播放／輸出」勾選「PDF 每頁自動輪播」，以素材參數的秒數控制每頁停留時間；預設手動翻頁。
- **PowerPoint 原生放映**：Windows 必須已安裝並啟用 Microsoft PowerPoint 桌面版。透過 PowerPoint 原生引擎放映，啟用動畫與旁白，保留原檔的動畫、音效及內嵌影音；由 PowerPoint／系統音量控制聲音。原檔以唯讀副本開啟，結束時僅關閉本次放映。
- **PPT 螢幕與 CUE**：使用「輸出螢幕」選擇原生放映的螢幕；CUE 記錄投影片與動畫步驟。預設由按鍵前進，若需要原有換頁時間，可在「簡報」勾選「PPT 使用原有自動換頁時間」。召回動畫步驟由原生引擎重建，不是影片音效播放位置的逐毫秒恢復。

PowerPoint 使用獨立原生輸出視窗，以保留原生動畫和音效；中央顯示放映狀態，不擷取 PowerPoint 畫面。PPT 不提供多畫面格子或畫布變形；需回到單畫面播放。PDF 在 Windows 與 Mac 都可使用，Mac 不提供此版 PowerPoint 自動化整合。

## 外接簡報筆

支援 USB／藍牙鍵盤模式簡報筆，連接 Windows 後不需額外配對本程式。啟用「簡報筆」後，讓 MediaCarousel 或 PowerPoint 原生放映視窗取得焦點：

| 按鍵 | PDF | PowerPoint |
| --- | --- | --- |
| Page Down、右／下、空白鍵、N、Enter | 下一頁 | 下一動畫步驟，完成後下一張 |
| Page Up、左／上、P、Backspace | 上一頁 | 上一步／上一張 |
| Home／End | 第一頁／最後一頁 | 第一張／最後一張 |
| B | 切換黑畫面 | 切換原生黑畫面 |
| Esc | 結束簡報 | 結束放映 |
| F5（MediaCarousel） | 播放列表所選簡報 | 播放列表所選簡報 |

文字輸入欄、數值輸入欄與對話框不攔截簡報按鍵。使用廠商專用協定的簡報筆需先在其軟體設定為上述鍵盤按鍵。

## 驗證範圍

新增測試涵蓋真實三頁 PDF 繪製、手動／自動翻頁、輸入焦點、簡報筆按鍵開關、黑畫面、CUE 與專案保存還原、多畫面來源獨立性，以及 PowerPoint 動畫步驟與唯讀開關生命週期的 COM 模擬測試。

原生打包啟動測試會檢查 PDF 繪製；Windows 另檢查隨程式封裝的 COM 橋接模組。CI 沒有安裝 Microsoft Office，也未連接實體簡報筆；動畫、音效及實體簡報筆仍需在安裝 PowerPoint 的目標 Windows 電腦驗證。
