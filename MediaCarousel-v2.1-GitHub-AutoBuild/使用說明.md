# Media Carousel 2.0 — 影音輪播工作台

**交付狀態：桌面程式原始碼與 Windows／Mac 打包工具。此 ZIP 尚未包含已打包的 Windows EXE 或 Mac APP，不能解壓縮後直接當成免安裝程式使用。**

這是一個原生 Qt 桌面介面，不需要瀏覽器。此次延續 v1.0 專案，加入影片片段、聲音、多畫面、外部擷取與場景記憶。Windows 與 Mac 的正式二進位檔仍需在各自系統打包及驗證；不要把這份原始碼包誤認為已驗證的正式執行檔。

## 全部功能

| 分類 | 功能與操作 |
|---|---|
| 影片播放 | 加入本機影片、播放／暫停／停止、上一個／下一個；雙擊清單項目開始播放。 |
| 播放清單 | 建立多份清單、命名、刪除、調整項目順序、拖入媒體檔。 |
| 輪播模式 | 本清單循環、所有清單依序輪播、單檔循環、播放一次。 |
| 圖片輪播 | JPG、PNG、BMP、WebP、TIFF 等；依 Qt 圖片解碼支援；各張 0.5–86400 秒，可整份清單批次套用。GIF 只顯示第一影格。 |
| 轉場 | 淡入淡出、淡出到黑再淡入、向左滑動、向右滑動、縮放淡入、直接切換、隨機效果；轉場時間 0.1–10 秒。 |
| 影片片段 | 每支影片設定開始／結束秒數；結束 0 表示原片尾。非破壞式播放剪輯，保留原片，不輸出新的剪輯影片。 |
| 聲音 | 主音量、單檔音量、單檔靜音；多畫面另有每個畫面的音量與靜音。三層音量相乘；轉場時音訊同步淡出／淡入。 |
| 單畫面進度 | 可拖曳進度條定位；影片以選定片段為範圍，圖片以顯示時間為範圍。多畫面有獨立進度，主進度條停用。 |
| 多畫面 | 同一個 1920×1080 畫布最多 12 個來源；每個清單畫面獨立輪播。 |
| 畫面配置 | 滑鼠拖曳位置、右下角拖曳大小；可輸入左／上／寬／高；上層／下層；2×2、3×2、4×3 自動排列。 |
| 畫面比例 | 完整顯示保留黑邊，或填滿裁切；多畫面可逐一設定。 |
| 外部擷取 | 螢幕、可擷取的應用程式視窗、攝影機及系統識別為攝影機的 USB／HDMI 擷取卡。來源加入後按播放才啟動。 |
| 場景記憶 | 新增具名稱的場景、載入、覆寫、刪除；記住來源、清單對應、位置、尺寸、圖層順序、畫面音量、靜音、比例與全域播放設定。 |
| 專案保存 | `.mcarousel` 同時保存清單、片段、聲音、目前配置及所有場景；可讀取 v1.0 舊專案；使用相對媒體路徑方便整個資料夾搬移。 |
| 獨立輸出 | 控制介面持續顯示預覽，另開播放輸出視窗；可選擇輸出螢幕及全螢幕；進入輸出會關閉編輯外框。 |
| 快捷鍵 | Space 播放／暫停、左右方向鍵上一個／下一個、F11 全螢幕、Esc 離開全螢幕。焦點在輸入欄位時按鍵可能由該欄位處理。 |
| 解碼資訊 | 「格式資訊」列出目前電腦實際可解碼的封裝與影片編碼；檔案遺失、解碼失敗或逾時會顯示錯誤。 |

## 快速操作

1. 加入媒體並建立播放清單；選中影片，輸入起訖秒數及音量，按「套用片段與音量」。
2. 單畫面：選擇輪播模式、轉場及時間，按播放。
3. 多畫面：按「＋清單畫面」，為每個畫面指定清單。最多 12 個。
4. 拖曳配置；右下角拖曳縮放，或輸入精確座標／尺寸。畫布邊界內的範圍會自動限制。
5. 加入外部擷取時選擇具體裝置、螢幕或視窗；來源只擷取影像，不擷取系統聲音／麥克風。
6. 按「記憶新場景」命名。變更現有場景用「覆寫」。場景會自動保存；可按「改名」重新命名。程式每兩秒保存目前清單、場景與版面，正常關閉時也會保存；下次啟動自動恢復為待播狀態。需要備份或移至其他電腦時，請另外「儲存專案」。
7. 載入場景會停止目前所有來源，還原配置後再按播放。視窗若重新開啟，通常需要刪除該擷取畫面再重新選擇；裝置不在時不會自動改抓其他來源。
8. 選擇輸出螢幕後全螢幕輸出；想調整配置請重新勾選編輯框。輸出視窗與預覽使用相同畫布，勾選編輯框會同時出現在兩者。

## 在 Windows 產出 EXE

建置電腦須安裝 Python 3.11／3.12 及能下載 Python 套件的網路。

1. 解壓縮，雙擊 `Build-Windows.bat`。
2. 工具建立建置環境、安裝依賴、跑資料測試，再打包。
3. 成功後產物為 `dist/MediaCarousel/MediaCarousel.exe`。
4. **將整個 `dist/MediaCarousel` 資料夾**複製到播放電腦；不能只取 EXE。
5. 播放電腦可直接開 EXE，不必安裝 Python。這個步驟須先在 Windows 上實際完成，ZIP 裡目前沒有該 EXE。

## 在 Mac 產出 APP（含 Apple Silicon）

建置 Mac 須安裝 Python 3.11／3.12 及能下載套件的網路。M3 Max 請使用原生 arm64 Python，產生適用 Apple Silicon 的版本；Intel Mac 應另外在 Intel 環境打包。

1. 解壓縮，雙擊 `Build-Mac.command`。若執行權限未保留，在 Terminal 執行 `chmod +x Build-Mac.command` 後再開啟。
2. 成功後產物為 `dist/MediaCarousel.app`，可複製至「應用程式」開啟。
3. 此流程產生本機用途的套件，尚未經 Apple 開發者簽署／公證；系統若攔阻，需用 macOS 提供的「仍要開啟」流程。正式公開發佈還需簽署與公證。
4. 螢幕／視窗擷取需要系統的螢幕錄製權限；攝影機需要相機權限。設定後可能需重新啟動程式。

## 以原始碼試用

`Start-Windows.bat` 或 `Start-Mac.command` 可在已安裝 Python 的電腦建立執行環境後開啟程式。第一次需要網路安裝 PySide6。這兩個啟動檔是原始碼啟動工具，並非免安裝 EXE／APP。

## 相容性與實際限制

- 使用 Qt FFmpeg 媒體後端。副檔名不等於影片編碼；實際播放能力依 Qt、系統、硬體與影片內容而定，不能保證「所有格式」。受 DRM 保護、損壞或特殊編碼媒體需另行處理。
- 暫未內建轉檔或剪輯影片輸出，也沒有 NDI、Spout、Syphon、網路串流、擷取系統聲音或專業 SDK 擷取卡介接。
- 多畫面上限是 12；12 支高解析影片的即時性能必須在目標電腦測量。雙素材轉場時解碼資源需求會增加。
- 圖片顯示時間從轉場完成後開始計算。影片包含轉場期間播放的時間；片段很短而轉場很長時，應降低轉場時間或用直接切換。
- 在相同螢幕擷取自身播放器可能形成畫面回授；實務上應選擇不同來源螢幕或特定外部視窗。
- 媒體本體沒有內嵌到專案檔案；請與專案一起保留。專案儲存會記住檔案路徑，外部擷取來源不會因開啟專案自動啟動。

## 本次驗證紀錄（2026-10-12）

已在 Linux／Qt 6.8.3 的無實體螢幕環境完成：

- 6 項資料測試：輪播規則、相對路徑與場景還原、v1 格式相容、片段邊界、非法資料拒絕、座標限制。
- 單畫面及多畫面的七種轉場選項、獨立輸出視窗與控制端預覽。
- 桌面介面初始化、單張圖片播放／暫停／繼續、12 個獨立圖片播放器、4×3 配置、尺寸設定、場景往返還原。
- 實際 H.264／AAC MP4 解碼；單畫面及多畫面影片從指定秒數開始，在指定終點停止。

尚未驗證：Windows／Mac 二進位建置與啟動、實體音訊輸出、外部攝影機／擷取卡／螢幕擷取權限、12 支影片同播效能、真實雙螢幕輸出。完成這些目標系統驗證前，版本狀態為 **2.0 待驗證版**。

開發者可執行：`python -m unittest discover -s . -p test_model.py`。介面測試為 `python test_gui.py`；若要測試影片，設環境變數 `MEDIA_TEST_CLIP` 指向約四秒以上的測試 MP4。
