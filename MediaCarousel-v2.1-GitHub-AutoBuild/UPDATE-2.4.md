# MediaCarousel 2.4 · 介面整合

四種整體風格與四種版型可分開選擇，共 16 種搭配。上方工具列「風格／配置」或「介面外觀」選單都可切換：

- 導播控台：左素材、中央預覽、右音量與參數、下方 CUE。
- 明亮工作室：左素材／CUE，參數與音量放在下方。
- 舞台演出：大型預覽、底部 CUE 快速控制、右側直式音量表；素材與參數按需開啟。
- 精簡工作台：右側素材／CUE／參數分頁，音量表獨立保留，中央預覽最大化。

素材的秒數、剪輯、音量設定收進「素材參數」。多畫面、尺寸／聲音、播放／輸出改用分頁。專案管理集中在選單；常用播放、拖曳縮放、滿版及主音量保留於預覽下方。

介面偏好與 CUE 分開保存，重新開啟可恢復所選風格／配置。召回 CUE 不會改動操作員的介面。切換介面只移動既有面板，保留播放器、來源、畫布、格子與 CUE。

「素材」「CUE」「參數」工具列按鈕及「檢視」選單可重新開啟收起的面板；「介面外觀 → 恢復導播控台預設」可恢復標準配置。

驗證：16 種搭配、偏好保存還原、CUE 鍵盤選取與召回、單／多畫面物件與幾何保持、實際 H.264/AAC 播放期間切換介面，以及既有畫布、滿版、CUE、黑場與模型測試。
