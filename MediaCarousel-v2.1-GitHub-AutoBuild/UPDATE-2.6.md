# MediaCarousel 2.6 · 影片 FADER 與即時靜音

右側「音訊監看／影片 FADER」新增直立音量推桿，依播放器實際音軌資訊顯示，並提供檔名、通道編號、dB 刻度、音量百分比與醒目的 MUTE 按鈕。

- 只顯示正在使用且含音軌的影片；無音軌影片、圖片、PDF、黑畫面與外部 PowerPoint 不列入此區塊。
- 影片暫停或已靜音時保留推桿，方便調整及解除靜音；停止播放後移除。沒有符合來源時，FADER 區塊自動收起。
- 推桿採對數 dB 刻度，頂端 0 dB＝素材音量 100%，底端為零音量；主音量與格子音量仍共同作用。
- MUTE 與音量直接更新播放中的音訊輸出，不重新載入、不重設播放位置。原本「素材靜音／素材音量」與格子靜音也可即時作用於其對應的播放來源。
- 多畫面按播放實例分開控制，即使兩格播放同一檔案，也不會一起改動。轉場中的淡入／淡出影片分別列出，各自控制；淡出完成後移除舊通道。
- 調整同步到該播放來源與 CUE 快照，並可隨專案保存。已記錄的 CUE 保持原本設定，需覆寫或重新記錄才更新。
- 多通道可水平捲動；音訊表與 FADER 並排，以保留中央預覽及右側參數的操作空間。四種風格與四種配置皆沿用。

驗證使用真正的 H.264/AAC 與無音軌 H.264 檔案，涵蓋音軌篩選、播放／暫停時的音量與靜音、播放器／來源不重建、播放位置持續前進、相同檔案的獨立實例、轉場來源綁定、CUE 還原及 16 種風格／配置搭配。另執行既有模型、畫布、滿版、格子、PDF 與簡報控制回歸測試。
