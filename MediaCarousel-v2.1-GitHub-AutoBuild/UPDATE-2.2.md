# MediaCarousel 2.2

- 「播放一次」可在結束時保留最後一幀；再次播放可重新開始，停止仍會清空畫面。
- 上方「顯示／收起右側面板」控制整個面板；尺寸、音量與圖層選項可以展開／收合。
- 獨立輸出與預覽不繪製格子名稱、拖曳把手或編輯框，操作畫布可繼續編輯。
- 多畫面效能模式預設開啟，使用直接切換降低同時解碼負擔。單一來源循環重用播放器，無變更時不重寫自動保存檔。
- 新增左右、上下、三欄、三列、主畫面加側欄、子母畫面及自訂欄列；可拖曳尺寸並儲存自訂面板／場景。
- 「畫布像素／4K」可選 3840×2160、4096×2160、直式 4K 或自訂尺寸（寬高最高 4096）。調整畫布時，現有格子按比例縮放，並保存至專案。

4K 全螢幕輸出需要作業系統將目標顯示器設定為對應解析度；播放流暢度仍取決於影片編碼、同時播放數量及顯示卡解碼能力。效能模式會停用多畫面轉場動畫，可取消勾選恢復。

驗證：不同長寬比照片與影片畫面填滿、4K 與直式畫布專案保存／還原、操作端編輯時乾淨輸出、實際 H.264 片尾停格與再次播放、單一影片重用播放器循環。實體 4K 顯示器及使用者現場多路影片壓力測試需於目標電腦確認。
