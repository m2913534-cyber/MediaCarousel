# MediaCarousel 2.7 · 保留畫質的播放效率優化

- 穩定播放時不再每 16 毫秒重寫相同的音量／靜音值；音量變動、即時靜音、外部控制與每一步轉場音量包絡仍立即更新，不重新載入或定位影片。
- 多畫面調整音量／靜音時不再重設影像幾何。只有格子寬高改變才重新配置影像，保留強制滿版、各格獨立尺寸與位置。
- FADER 的檔名、讀數、推桿與區塊尺寸只在變動時更新，避免播放期間反覆排版。
- 音量表以向量運算處理完整的解碼 PCM 樣本，保留 L/R 峰值、RMS、單聲道複製及原本顯示頻率；不抽樣、不減少影片幀數。多聲道維持原本的前兩聲道監看方式。
- 每次播放輪詢只讀取一次影片位置，減少跨 Python／Qt 呼叫。

影片來源不重新編碼、不產生代理檔，不更改解析度、碼率、播放幀率、畫布、平滑縮放、轉場或原有 Qt 自動硬體解碼選擇。播放控制的 16 毫秒計時器保持原設定。

## 驗證

Linux／Qt 6.8.3 的 PCM 分析基準：48 kHz、立體聲 Int16、每次 50 ms 緩衝，5 組各 500 次，CPU 時間中位數由 0.596 ms 降至 0.129 ms，約 4.6 倍。此數值只代表音量表分析，不代表整個程式或影片播放倍速；整體流暢度仍取決於影片編碼、同時播放數量及硬體。

四種 PCM 格式、單聲道／立體聲／六聲道的全部樣本與獨立參考計算誤差小於 1e-12。1000 次相同音量輪詢，每個屬性只寫入一次；100 個不同淡入步驟全部保留。12 格音訊調整不觸發影像重新配置，修改尺寸則正常配置。

既有 4K／直式畫布、輸出無編輯標示、各種寬高滿版、自由寬高、CUE、PDF、簡報筆、PowerPoint 控制契約、16 種風格／配置，以及真實 H.264/AAC 與無音軌影片測試均通過。Windows、Apple Silicon、Intel Mac 封裝各自執行原生啟動與 PCM 分析依賴檢查。尚未在使用者的投影設備上實測多路 4K 吞吐量。
