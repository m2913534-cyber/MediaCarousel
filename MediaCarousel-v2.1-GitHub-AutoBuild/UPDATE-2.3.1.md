# MediaCarousel 2.3.1

- 多畫面照片、影片、片尾停格及外部擷取改為按格子的寬／高分別拉伸鋪滿，完整保留來源範圍；格子比例不同時影像會變形。
- 拖曳格子尺寸只更新顯示幾何，不重載、不跳轉或停止播放器。其他格子不受此幾何更新影響。
- 多畫面選檔沿用獨立來源快照，不增加、複製或修改左側列表及項目。
- 影片編輯視窗可獨立開啟並操作主控台；開啟、預覽、套用或取消編輯均不停止主輸出。編輯會保存至列表，重新播放或重新套用來源時生效，避免現場輸出跳動。
- 左側片段／音量設定的套用同樣不停止輸出。

驗證：照片／影片四角標記在橫／直格子及反覆縮放後完整保留，列表及項目數不變；實際 H.264/AAC 單／多畫面在調整大小、開啟編輯、儲存及套用設定時，播放器與播放位置持續運作。CUE、黑場、畫布及既有模型測試通過。
