# MediaCarousel 2.5.1 · 單畫面自由寬高

選取並播放素材後，按預覽下方的「拖曳縮放」，即可使用八個控制點：

- 左／右邊：只改寬度，另一邊固定。
- 上／下邊：只改高度，另一邊固定。
- 四個角：寬、高分別跟隨滑鼠移動，可自由拉伸，不鎖定長寬比例。
- 拖曳中央：移動畫面。
- Shift＋滾輪：只調寬度；Alt＋滾輪：只調高度。單獨使用滾輪則放大／縮小目前的形狀。
- 「一鍵滿版」：清除位移及獨立寬高，強制填滿目前畫布。

橫式及直式畫布皆可使用；適用程式內播放的圖片、影片與 PDF。控制框跟隨媒體顯示範圍，獨立預覽及輸出視窗不顯示編輯框或控制點。PowerPoint 維持原生獨立放映。

寬度、高度及位置會存入素材、CUE 與專案；舊版等比縮放參數可自動沿用。多畫面維持格子拖曳方式，影像仍強制填滿格子。

驗證包含：橫／直式畫布的八個滑鼠控制點、對邊固定、寬高獨立、影像框定位、移動、滿版重設、輸出無控制點、CUE／專案尺寸還原，以及舊版縮放參數相容性。
